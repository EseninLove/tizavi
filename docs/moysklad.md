# МойСклад: первый этап подключения

Владелец магазина открывает `/admin/moysklad`, вставляет API-токен и нажимает «Проверить и сохранить токен». Пароль аккаунта не нужен. Токен проверяется до замены рабочего подключения, хранится зашифрованным с существующей серверной защитой ключей и не возвращается клиенту. После подключения выбираются организация, склад и тип цен из справочников именно этого аккаунта.

## Что уже реализовано

- Отдельный раздел админки и ссылка из настроек, доступ только владельцу, защита от подмены Origin, ограничение частоты проверок и аудит изменений.
- Серверные GET-запросы JSON API 1.2 к фиксированному `api.moysklad.ru`: организации, склады, типы цен и первые пять позиций ассортимента. Переходы по редиректам запрещены, ошибки очищены от секретов, размер ответа и время запроса ограничены.
- Постраничная загрузка организаций и складов (до 2000 записей каждого справочника, без молчаливого усечения), проверка выбранных идентификаторов по полученному списку.
- Проверка соединения и замена токена, обновление справочников, обзор пустого/заполненного каталога, удаление только локального подключения. Смена токена сбрасывает выбор организации/склада/цен, но не меняет каталог сайта.
- Миграция 009 создаёт только таблицу настроек; существующие товары, цены, покупатели, заказы и оплаты не изменяются.

## Получение токена

В интерфейсе МоегоСклада: меню пользователя → **Настройки → Токены → +Токен**. Создание нового ключа доступа выполняет владелец. Желательно использовать отдельного сотрудника с доступом к нужным организации, складу и справочникам. Токен не передавать через чат и не сохранять в Git. После его создания вставить значение непосредственно в закрытую форму магазина.

## Следующие этапы — пока не реализованы

Текущий аккаунт пустой. Сначала необходимы реальные товары, единицы измерения, цены и начальные остатки. Нельзя придумывать остатки или закупочные цены. После наполнения нужен предварительный просмотр импорта с явной проверкой сопоставления товаров, категорий и складов.

Автоматическая синхронизация сейчас выключена и не запускается из этой страницы. Каталог сайта не заменяется автоматически. Ещё требуются:

1. Постоянные соответствия идентификаторов товаров, модификаций, категорий и складов. Названия не использовать как уникальный ключ.
2. Импорт выбранного типа цен в рублях, единиц и фотографий с учётом весовых товаров. Разделить остаток, резерв и доступное количество. Не переносить поля рейтингов и отзывов в складской учёт.
3. Проверка и резервирование доступного количества на сервере при оформлении заказа, защита от одновременных покупок, отмен и истечения резерва.
4. Надёжная очередь экспорта заказов с повторными попытками и защитой от дублей, сопоставление покупателей/доставки/налогов. Платежи и подписки продолжают подтверждаться только агрегатором; состояние документа МоегоСклада само по себе не подтверждает оплату.
5. Фоновое расписание SprintHost, журнал обмена и при необходимости вебхуки с повторным чтением данных через API. Не загружать ассортимент во время каждого открытия витрины.
6. Проверка на реальном аккаунте: цена/наличие, дубль уведомления, недоступность API, отмена и возврат. Не создавать фиктивные заказы/оплаты в рабочем аккаунте.
